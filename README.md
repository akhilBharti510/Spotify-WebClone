## Overview
Spotify Web Clone is a **frontend-only music player** inspired by Spotify, built entirely using **HTML, CSS, and JavaScript**. It allows users to **play songs, manage playlists, search tracks, and create an account** with secure login functionality — all stored in the browser's `localStorage`.  

This project demonstrates a **fully interactive music player** with **modern UI/UX**, making it perfect for showcasing frontend skills.

---

## Features
- 🎧 **Music Playback**
  - Play, pause, skip next/previous tracks  
  - Seekbar with live time updates  
  - Volume control and mute/unmute  

- 📂 **Album Management**
  - Multiple albums with separate song lists  
  - Album cards with cover image, title, and description  

- 🔍 **Search Songs**
  - Real-time song search filtering  

- 🔒 **User Authentication**
  - Signup / Login system  
  - Passwords **hashed with SHA-256**  
  - Password strength validation  
  - Persistent login via `localStorage`  

- 📱 **Responsive UI**
  - Hamburger menu for navigation  
  - Mobile-friendly and modern design  

---

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)  
- **Storage:** `localStorage` for users and session  
- **Security:** Client-side SHA-256 password hashing (Web Crypto API)

## Usage
1. **Clone the repository**
    git clone https://github.com/akhilBharti510/Spotify-WebClone.git

2. **Open index.html in your browser**

3. **Signup/Login to enjoy a personalized experience**

4. **Browse albums and play your favorite tracks**

5. **Search songs or control playback with the player interface**
